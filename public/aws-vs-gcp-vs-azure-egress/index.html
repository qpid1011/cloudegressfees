Objective Retention, Ratio & Engineering Caveats

  • Hyperscaler Public Internet Tiers: GCP Standard bills $0.12/GB ($77,040/yr at 20 TB + 50 TB/mo), AWS S3 bills $0.09/GB ($59,412/yr), and Azure Blob Hot bills $0.087/GB ($57,109/yr).
  • Free-Tier Allowances: AWS S3 and Azure include 100 GB/mo free internet egress, which offsets less than 0.2% of a 50 TB/mo production workload.
  • Multi-Cloud Origin Offload: Syncing public read buckets to Cloudflare R2 ($3,600/yr) or Backblaze B2 ($1,440/yr) eliminates 94%–98% of hyperscaler bandwidth spend.

FinOps Engineering FAQ

Which of AWS, GCP, or Azure has the highest cloud egress fees?

On standard public internet routing, Google Cloud Storage is highest at $0.12/GB ($76,800/yr for 20 TB stored + 50 TB/mo egress), followed by AWS S3 at $0.09/GB ($59,412/yr) and Azure Blob Hot at $0.087/GB ($56,416/yr).

How much can enterprises save moving public egress off AWS, GCP, or Azure?

Offloading 20 TB stored + 50 TB/mo public downloads to Backblaze B2 Cloud Storage ($1,440/yr) saves $57,972/yr versus AWS S3 and over $73,000/yr versus GCP Standard.
