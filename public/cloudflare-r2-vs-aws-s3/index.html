FinOps Engineering FAQ

How much cheaper is Cloudflare R2 than AWS S3 for 20 TB stored and 50 TB/mo egress?

Cloudflare R2 costs $300/mo ($3,600/yr) vs $4,951/mo ($59,412/yr) on AWS S3 Standard—an annual FinOps reduction of $55,812/yr (94% lower TCO), driven by eliminating $4,491/mo in AWS outbound bandwidth charges.

Does Cloudflare R2 enforce an egress-to-storage ratio limit or minimum retention period?

No. Unlike 90-day retention clouds or 3x stored multiplier tiers, Cloudflare R2 charges $0.00/GB public internet egress at any egress-to-storage ratio with no minimum object duration charge.

When should teams choose AWS S3 or Backblaze B2 over Cloudflare R2?

Keep data in AWS S3 when workloads rely on tight in-region VPC compute (Athena, EMR, S3 Express One Zone) with minimal public internet egress; choose Backblaze B2 ($1,440/yr at 20 TB + 50 TB/mo) when stored volume is large and monthly downloads stay under 3x stored capacity or flow through Cloudflare CDN.
